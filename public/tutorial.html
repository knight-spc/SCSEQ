1. Introduction to the Platform

The SCSEQ platform adopts a project-based workflow in which all analytical tasks must be created and executed under a project. This design ensures that data remain isolated between projects and that analytical results are traceable across different stages. This tutorial introduces the initial workflow from logging into the platform to accessing result visualizations.

2. Interface Overview

After logging into the SCSEQ cloud platform, the user enters the Welcome Page. The sidebar on the left serves as the main entry point for all subsequent operations and contains three core modules:

  • Project Management — Workspace for creating and managing sequencing analysis projects. Users can view all projects under their account and inspect task information for each project.
  • Parameter Setup — Used to check uploaded datasets and configure preprocessing parameters. Quality control metrics are displayed using violin plots.
  • Result Visualization — Provides downstream analytical modules and visual outputs.

3. Project Management

Project Management functions as the core carrier of the analytical workflow. Multiple downstream analyses can be executed within the same project. If samples need to be added or removed, a new project must be created to prevent mixing historical outputs.

3.1 Creating a New Project

  1. Click New Project in the upper-left corner.
  2. Fill in the following fields in the dialog box:
  • Project Name — Suggested format “Tissue–Objective” (e.g., Liver–Tumor)
  • Species — Select species from the dropdown menu
  • Description (optional) — Brief notes on sample source or experiment purpose

Upload input data according to the required file format. The platform validates file structure before allowing submission.

Click Confirm. The system generates a project directory, returns a project ID, computes initial quality metrics, and redirects to Parameter Setup.

3.2 Task Information

Project task information can be viewed by clicking View on the lower-right corner of a project card. The task dialog contains:

  • Task Tree — The root node represents raw project data. The second-level nodes represent cell annotation models, and the third-level nodes correspond to downstream analyses such as GO enrichment, cell–cell communication, CNV, pseudotime, or pan-cancer analysis. Each task node stores metadata.
  • Task Table — Displays detailed task information including task type, parameter settings, running status, submission timestamp, and operation options. Users may view results or delete task records. Deleting a task removes its outputs.

4. Parameter Setup

The Parameter Setup page displays basic QC plots and allows users to define preprocessing thresholds.

Quality Control Metrics

  • nFeature_RNA — Number of detected genes per cell
  • nCount_RNA — Total UMI counts per cell
  • percent.mt — Maximum allowed mitochondrial gene percentage

Clustering Method

Users may select either UMAP or t-SNE for dimensionality reduction.

After confirming parameters, click Submit to proceed to Result Visualization.

5. Result Visualization — Cell Annotation

Cell annotation assigns biological identities (e.g., T cells, B cells, tumor cells) to clusters derived from upstream preprocessing. Accurate annotation serves as the foundation for downstream analysis including differential expression, communication, and trajectory inference.

5.1 Module Description

  • Cluster visualization
  • Post-QC violin plots
  • Cell proportion charts

Proportion charts update when annotation labels change.

5.2 Pre-Annotation Checklist

  1. Verify input clustering quality
    Clusters should be visually separable on UMAP. Populations with fewer than 50 cells may yield uncertain labels. If clustering resolution is too high (>1.5), reducing resolution is recommended.
  2. Select annotation strategy
    SCSEQ provides three annotation methods:
    • SingleR — Reference-based matching for fast initial annotation
    • Celltypist — Machine learning models with training support
    • LLM-based annotation — Large language model + RAG with interpretable suggestions
    Cross-validation between methods is recommended.

5.3 Operation Steps

  1. Click Result Visualization
  2. Select Cell Annotation
  3. Choose a reference dataset and execute

After completion, the outputs include:

  • UMAP colored by annotation
  • Cell proportion plots (percentage or absolute, with configurable grouping)

5.4 Optional — Custom Model Training

Users may upload annotated datasets to train a custom model:

Requirements: Annotated .h5ad file containing a cell_type column

Training steps:

  1. Select reference mode: Train your reference
  2. Upload file
  3. Provide model name

Training takes ~10–30 minutes and produces a reusable model.

Custom models can be invoked for future projects without retraining.

6. Gene Enrichment Analysis

Gene enrichment analysis links differential gene signatures with functional interpretation. After differential expression analysis, marker genes are used to identify relevant biological processes and pathways.

6.1 Module Description

  • Differential gene table
  • Bubble plot of marker genes
  • GO enrichment bar chart
  • Feature gene scatter plot
  • Feature gene violin plot

6.2 Prerequisites

  1. Marker gene computation
    The platform derives top marker genes per cell type after cell annotation.
  2. Inspect expression patterns
    Bubble plots encode expression proportion (dot size) and expression level (color scale), enabling identification of type-specific markers.

Scatter and violin plots display gene distribution across cell types.

6.3 Operation Steps

  1. Navigate to Gene Enrichment Analysis
  2. Select target cell type

Outputs include GO bar chart:

  • Y-axis: GO terms sorted by p-value
  • X-axis: Count of enriched genes
  • Color scale: Significance level

7. Cell-Cell Communication Analysis

Cell–cell communication evaluates potential signaling interactions among annotated cell groups using ligand–receptor models. SCSEQ integrates CellChat and CellChatDB for inference.

7.1 Module Description

  • Circular interaction network
  • Communication heatmap

7.2 Prerequisites

  • Annotated dataset with cell_type
  • Sufficient cell count per type (≥50 cells recommended)

7.3 Operation Steps

  1. Navigate to Cell–Cell Communication
  2. Click Run
  3. Choose visualization mode (count or weight)

Outputs include:

Circular plot: Used to display the overall interaction network among cell groups. The width or arc length of the circle represents the total communication strength of each cell group as a sender or receiver, while the connecting chords represent the signal magnitude between different cell groups, helping to identify dominant communication nodes.

Heatmap: Rows and columns represent sender and receiver cell groups, and the color intensity reflects communication strength or the number of ligand–receptor pairs, allowing rapid identification of active cell pairs.

8. Copy Number Variation (CNV)

CNV inference detects chromosomal amplification or deletion signals indirectly from gene expression continuity patterns. SCSEQ integrates inferCNV for visualization.

8.1 Module Description

  • Heatmap visualization
  • Reference cell selection panel

8.2 Prerequisites

  • Annotated dataset
  • ≥50 cells per cell type

8.3 Operation Steps

  1. Navigate to CNV
  2. Select target cell groups and reference cell types
  3. Execute analysis

Outputs include:

InferCNV heatmap:

  • X-axis: Genes ordered by genomic position
  • Y-axis: sCells ordered by cell type and CNV pattern
  • Color: gene expression levels (red = high expression, blue = low expression)
  • Red — elevated expression (amplification)
  • Blue — reduced expression (deletion)
  • White — no major change

9. Pseudotime Analysis

Pseudotime analysis reconstructs continuous cell-state transitions from static single-cell profiles. SCSEQ uses Monocle3 to infer trajectories and visualize gene dynamics.

9.1 Module Description

  • Pseudotime trajectories
  • Cell type mapping on trajectories
  • Gene expression trends along pseudotime

9.2 Prerequisites

  • Annotated dataset
  • ≥50 cells per type
  • Highly variable gene selection completed

9.3 Operation Steps

  1. Navigate to Pseudotime Analysis
  2. Select target cells
  3. Execute analysis
  4. Optionally select genes for trend visualization

Outputs include:

Pseudotime heatmap:

  • X-axis: genomic regions (genes ordered by chromosomal position)
  • Y-axis: single cells (ordered by pseudotime values)
  • Color: gene expression levels (red = high expression, blue = low expression)

Trajectory structure plot: Cell annotation labels are overlaid on the trajectory backbone to verify whether the inferred trajectory aligns with biological logic.

Gene expression trend plot:

  • X-axis: pseudotime (normalized to 0–1)
  • Y-axis: gene expression levels (log2-transformed)
  • Fitted curve: LOESS smoothing curve showing the overall trend

10. Pan-Cancer Analysis

Pan-cancer analysis compares molecular signatures across multiple cancer types to reveal shared mechanisms and heterogeneity.

10.1 Module Description

  • Expression boxplots
  • Methylation correlation heatmaps
  • Immune infiltration correlation matrices
  • Survival forest plots

10.2 Prerequisites

  • Annotated dataset
  • ≥50 cells per type
  • Highly variable gene selection completed

10.3 Operation Steps

  1. Navigate to Pan-Cancer Analysis
  2. Select target gene from dropdown
  3. Submit analysis

Outputs include:

Expression differential boxplot: The x-axis represents cancer types, and the y-axis represents normalized expression levels.

Methylation correlation heatmap: Rows correspond to CpG sites and columns correspond to cancer types. Colors represent Spearman correlation coefficients.

Immune infiltration correlation heatmap: Colors represent Pearson correlation coefficients with significance annotations.

Survival forest plot: Horizontal lines represent 95% confidence intervals, and squares mark hazard ratio point estimates.
